## 顺序、交付和验收

1. **本地固定目标到人工提交确认页**：手机本地完成目标选择、数量、已保存观演人选择与金额核对，停在确认页交给本人复核。允许的动作集合不含提交或支付。配置、等时、读页、决策、点击均在手机；桌面配对接口不提供遥控启动。未知布局停止，不猜坐标。已知选票结构可在用户明确授权后使用本地 OCR 和选中边框证据，确认页仅允许原生读取，禁止截图。
2. **触摸证据**：独立核对 minitouch 固定来源、Android API29/华为限制和已安装依赖；受控测试只操作本应用合成按钮。分别计量派发耗时与可观察效果耗时，预热和交错顺序、成功率、超时及样本数必须报告。不可用后端记录原因，不用零耗时替代样本，也不以官方注释推导实测速度。
3. **优先/备选/等待**：授权目标按顺序，预算和数量为硬边界；优先窗口结束后才启用备选。库存等待有截止时间及退避；重复本地读页不是主动刷新成功。没有已验证刷新入口时仅报告被动观察，不能宣称持续捡漏已经接通。
4. **生命周期**：手动停止、锁屏、无障碍失效、非大麦前台、未知/登录/验证页、截止时间均禁止后续点击；进程重启不自动恢复。动作代次和当前树验证防止延迟点击。此增量不提供提交动作，因此不改变既有提交账本；完整跨电脑/手机提交互斥通过前禁止打开手机自动提交。
